# Wallpapers

432 wallpapers organized by source repo and dominant color. **66 MB total.**

All images converted to **AVIF** at max 3840×2160, each under 1 MB.

## Structure

Each top-level folder is a source repo. Images are grouped into color
subdirectories based on dominant hue (extracted via color quantization).
