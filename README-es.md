# Fondos de pantalla

432 fondos organizados por repo de origen y color dominante. **66 MB total.**

Todas las imágenes convertidas a **AVIF** a max 3840×2160, cada una bajo 1 MB.

## Estructura

Cada carpeta raíz es un repo de origen. Las imágenes se agrupan en
subcarpetas por color dominante (extraído por cuantización de color).
